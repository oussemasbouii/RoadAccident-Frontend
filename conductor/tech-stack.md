# Tech Stack

## Language & Core Framework
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **Frontend Framework:** [React 18.2.0](https://reactjs.org/)
- **Build Tool:** [Vite 5.0.8](https://vitejs.dev/)

## UI & Styling
- **UI Framework:** [Material UI (MUI) 7.3.8](https://mui.com/material-ui/)
- **Utility CSS:** [Tailwind CSS 4.1.13](https://tailwindcss.com/)
- **Icons:** [@mui/icons-material](https://mui.com/material-ui/material-icons/), [react-icons](https://react-icons.github.io/react-icons/)
- **Transitions/Animations:** [React Hot Toast](https://react-hot-toast.com/) for notifications.

## State Management & API
- **State Management:** [Redux Toolkit (@reduxjs/toolkit)](https://redux-toolkit.js.org/)
- **API Client:** [Axios 1.6.5](https://axios-http.com/)
- **Real-time Communication:** [Socket.io-client 4.7.2](https://socket.io/)

## Data Utilities & Exporting
- **Date Handling:** [date-fns](https://date-fns.org/)
- **Excel Export:** [xlsx](https://sheetjs.com/)
- **PDF Export:** [jspdf](https://github.com/parallax/jsPDF), [html2canvas](https://html2canvas.hertzen.com/)
- **Word Export:** [docx](https://docx.js.org/)
- **Zip Compression:** [jszip](https://stuk.github.io/jszip/)
- **UUID Generation:** [uuid](https://github.com/uuidjs/uuid)

## Linting & Formatting
- **Linter:** [ESLint 8.56.0](https://eslint.org/)
- **Formatter:** [Prettier 3.1.1](https://prettier.io/)
